`system-overview.drawio` is a one-page draw.io diagram of the voice pipeline (capture, recognition, evaluation, verdict, decision, response, build-time content, orchestration), with the D0 / D1 / N determinism classes colour-coded; it is stored as uncompressed XML so it diffs in git.
Open it with [app.diagrams.net](https://app.diagrams.net) (File > Open from > Device) or the VS Code "Draw.io Integration" extension, and keep it in step with `implementation-plan.md` section 2. It was first drawn from the original design note, [docs/archive/nlp/history/high-level-docs.md](../../archive/nlp/history/high-level-docs.md), which is kept for history and is not updated.
