## Process notes (learned on PR #72)

- Do not commit in the feature checkout while a gate runs there; save reports first, then gate.
- Scripted runs default to 2 workers and settle the whole 16 km view before the first frame (minutes): measurements need `--workers 8 --no-settle --wait <s>`.
- Agents can stall on a lost background command: check `ps` for their worktree when a notification stops coming; nudge with SendMessage.
- The owner paused all agents once for machine load from parallel orchestrators: keep at most two or three agents, check `uptime` before each launch.
- Fresh seeds and `VOCATERRA_LOD_DIR` for every speed measurement: the far store under `~/.local/share/vocaterra/lod/` is shared by builds of the same world version.
