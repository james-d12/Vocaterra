## Process notes for the next orchestrator (learned on the B series)

- **Worktrees:** create them at absolute paths (`git worktree add -b <branch> /home/james/Dev/Vocaterra/.claude/worktrees/<id> <commit>`). On 2026-11-17, four were nested under the feature checkout by a relative path. Cut a worktree from the last *gated* commit, never from a gate's merge commit in flight.
- **The gate:** `merge-gate.sh` refuses untracked files too, so commit briefs and reports before starting a gate. It takes several `label:branch` pairs in one run, which suits small or independent branches.
- **Timing tests:** they measure CPU time, the fastest of three, in serial timing collections, with budgets twice the measured cost. On CI they are multiplied by 4 (B30). A wall-clock test that fails a gate is rerun alone before its merge is kept.
- **Agents:** the brief template ([docs/process/milestone-briefs.md](../process/milestone-briefs.md)) now forbids polling loops: wait for the notification instead. It also asks for one full run after the last merge of the feature branch, and short game runs in Release with `--far-view off`. Kill any `until grep ...` loops an agent leaves.
- **Parallel milestones that move the world's pins** (goldens, the save fixture's digest) conflict: the second to merge re-records.
- **Fuzz seeds:** engine or pack fixes for fuzz seeds need the owner's yes. Generator or oracle faults are fixed in the fuzz project (M98, M101).
