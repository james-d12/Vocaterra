# Audio sources

Every sound file under `game/assets/audio/` is CC0 (decision D-game-5, D-game-18). Each file is listed here with its source, pack, author, licence and edit.
`tests/Vocaterra.MonoGame.Tests/AudioProvenanceTests.cs` fails on a file that is not listed here, on a row whose file is missing or whose licence is not CC0,
and on a total size over the budget (15 MB for S24 and S25 together; S24 uses about 0.8 MB and S25 about 0.5 MB).

The cues that are not files are made in code at load (`src/Vocaterra.MonoGame/Frontend/SoundSynth.cs`: the push-to-talk beeps, the progress chimes, the sparkle,
the bottle and the fire's whoosh; `Frontend/SoundTextures.cs`: the dirt, gravel, sand and water steps, the birds' chirps and the fire's crackle). The ambient beds
(wind, the river, the waterfall, the village murmur and the evening insects) are loops made in code at load (`Frontend/AmbientLoops.cs`). They are generated from
fixed recipes and a fixed seed; they have no source file and no licence beyond the repository's. S25 uses no other source: the footsteps on grass, snow, wood and
concrete (for stone) are the Impact Sounds rows above.

## Licence check (2026-10-22)

Kenney's page for each pack lists the licence as CC0 ("CC0 licensed"), and each zip's `License.txt` reads "License (Creative Commons Zero, CC0)
http://creativecommons.org/publicdomain/zero/1.0/". The three packs used: Impact Sounds (https://kenney.nl/assets/impact-sounds),
RPG Audio (https://kenney.nl/assets/rpg-audio) and Interface Sounds (https://kenney.nl/assets/interface-sounds). No other source is used.
